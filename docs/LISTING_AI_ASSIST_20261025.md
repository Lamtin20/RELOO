## Observed verification and limitations

Private server services use Ollama0.40.11 with installed qwen3.5:4b (model ID d8b0f5e9760c),7GB/4CPU ceiling, and a384MiB/1CPU public-web service. Neither exposes host ports. The model starts with a neutral warm-up and readiness requires it to appear in /api/ps; weights must be provisioned beforehand, not downloaded on customer requests. Old production model/config remains unchanged until a separately reviewed release. Scoped advisor configuration does not reroute unrelated news/operations model calls.

Real CPU tests: warm constrained text selection about2s;640px photo identification around34–35s for the measured new examples. One repeated label request through RELOO API took17s; this is not a general latency promise. A public-camera photo did not establish the exact model and correctly required confirmation. A readable synthetic model label established Sony ILCE-7M4. Manufacturer lookup took6.09s uncached; a cached API enrichment took0.58s. Bare34.1/33.0MP numbers in manufacturer text are not treated as effective pixels without a matching label. Arbitrary variants, used condition and prices remain the owner's responsibility.

Eleven real HTTP boundary checks and32 browser fixture checks passed before final source freeze; final consolidated reports list subsequent results separately. Browser fixtures exercise four viewport sizes, manual-edit protection, explicit model confirmation, retry, unavailable/manual path, price preservation and opt-out persistence; they do not prove image recognition accuracy or a production publication. No real listing or transaction was created. Public Chợ Tốt reference was observed with REA only up to its authenticated posting entry; its internal AI algorithm was not observed or copied.

Agent-Reach integration packages its pinned WebChannel, not the full installation workflow. The upstream eager channel registry is replaced with an empty registry to exclude unrelated social/podcast/browser dependencies; MIT attribution is retained. Search can fail/rate-limit, in which case manual entry remains available. Only matching manufacturer domains are accepted. No search-provider credentials or browser sessions are imported.

No photo/prompt files or training store are created by this feature. Volatile model inference caches may remain in RAM until replaced, model unload or restart; immediate erasure is not promised. Existing listing photos/drafts retain their existing publication/storage lifecycle. The optional assistance preference is saved with the actor-bound24h browser draft. ## Operations

Use deploy/listing-ai/compose.listing-ai.yml for private sidecars and render_app_overlay.py to union existing app networks with the two private networks; do not replace the existing OCR, SSO, frontend or Agent network memberships. Create/verify the external private networks as internal=true and a separate egress network only for research. Provision the pinned model volume privately; start and verify model health before setting RELOO_LISTING_PHOTO_AI=1. Research credentials remain server-only. Qwen3.8 requires both sufficient hardware and RELOO_QWEN38_READY=1; the adapter alone does not install or activate it. Rollback disables the new scoped feature/config and restores the prior app/worker/renderers, preserving all existing data; never restore a stale database just to roll back this feature.
