The authenticated CRM now uses a horizontal header and grouped tool menu. Six groups cover operations, customers, communications, finance, safety and system management. All items are filtered through existing `crmViews`/permissions; unknown future permitted modules fall into an Other group rather than disappearing. Search supports Vietnamese with or without diacritics. Mobile uses the same complete menu in a scrollable single column. Escape/outside click closes the panel; active routes are identified.

The account panel shows the authenticated user's name/email, RELOO activation status, confirmed-email flag, CRM staff enablement, current role, allowed module count and MFA receipt expiry. These are sourced from the existing authenticated account/session and do not grant or activate anything. Staff see their read/edit scopes. Only users already allowed to manage staff see the permissions-management link. Existing server MFA expiry/role revocation checks and logout behavior remain in place.

Automatic news uses a hard maximum of 168 hours (seven rolling days), retaining stricter per-call limits when requested. Newest publication dates take priority; cached READY drafts only win a tie, so older generated content does not displace newer sources. Missing/invalid dates and dates more than five minutes ahead are rejected. Collection already distinguishes published dates from modified/lastmod dates. Before generating an article, the worker re-reads the source HTML and requires an explicit publication date. It uses the earlier of the saved feed date and page publication date, never a recent modification date. Freshness is checked again before creating images and atomically during publication.

Apply `news-freshness-week.sql` after backup: sets the current/default collection window to 168 hours and expires old queued candidates. A database trigger rejects any new transition to PUBLISHED for a stale/future/undated source, including cached READY/generated candidates. Existing published history is preserved. Existing budget, daily article quota, evidence review and duplicate checks are unchanged.
