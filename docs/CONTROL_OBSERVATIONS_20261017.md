Web process RSS/uptime is explicitly separate from the Linux/WSL infrastructure measurements below. APNs, email delivery confirmation beyond stored jobs, GSC, unconfigured providers and network traces outside instrumented APIs are not claimed as connected.

## Infrastructure extension

Added an independent root systemd collector (`reloo-observations.timer`, ~60 seconds). It samples Linux/WSL `/proc` CPU/RAM, `/srv/reloo` filesystem usage, a fixed allowlist of 14 container states/health/restart counts and the fixed public RELOO health URL. No Docker environment, log bodies, process IDs, hostnames, credentials or customer data are stored. The CRM/app does not receive the Docker socket or shell access. Snapshot fields are validated and bounded again on the API. Collector age over 180 seconds is explicitly stale. Container-running status alone is not a business/provider availability claim.

`operations-observations.sql` only adds observations/observed_at to the existing singleton heartbeat row, preserving the worker heartbeat independently. RLS/backend-only permissions remain, and security-lockdown is reapplied. The snapshot overwrites one row; no location/customer tracking history is created. Full host CPU/RAM measures Linux/WSL, not the Windows host as a whole.

Further investigation showed the environmental RSS has valid recent green-production and circular-economy articles excluded by overly narrow topic keywords. These explicit environmental synonyms are now included while the seven-day/attribution/evidence guards remain. A live read of the official feed produced two additional eligible articles; this is discovery evidence, not publication evidence.

Updated verification: 29 focused state/privacy/discovery/news/security tests passed; Python collector syntax check and scoped ESLint passed. Preview browser also checked infrastructure cards on mobile; values in preview screenshots are fixtures. A summary banner now exposes the latest newsroom outcome and a jump to the detailed observations without scrolling through the map.
