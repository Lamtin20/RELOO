## DMCA

Authenticated using the owner's existing DMCA Google sign-in, added reloo.vn and successfully validated domain ownership using the provider-issued root file. Claim flow returned `msg=valcompleted`. Existing sites and billing options were not edited. No takedown receiver/compliance subscription was enabled. Badge ID fe3278c5-9e96-4c76-a204-720c968aa755 is the actual signed-in account badge, not an anonymous sample.

The shared footer renders `a.dmca-badge` with a per-route certificate `refurl`, updated on SPA navigation. Newly created public pages using MarketplaceShell/Footer inherit it. Root metadata includes the domain verification marker; the validation file remains available. Authentication/account/CRM/transaction/API paths and query strings are excluded from per-page status URLs. The footer has a compact visible badge row on mobile.

The vendor's helper was inspected: it only appends the current document URL to badge links and runs on DOMContentLoaded. RELOO constructs the sanitized canonical link itself, supporting SPA routes without exposing private queries or executing third-party JS. The official image is proxied server-side per real public URL with the canonical Referer so the documented free-badge indexing request still occurs, while the browser receives a WebP derivative from RELOO. The proxy checks public page HTTP 200, rejects private/encoded private routes and arbitrary hosts, bounds vendor bytes/time, rate-limits, caches up to 1,000 paths for 12 hours, and falls back to the pre-imported WebP during a vendor outage. It does not expose customer IP/cookies to DMCA. No raw PNG is persisted as product/media fallback.

Ownership validation and badge enrollment do not equal vendor protection approval. At inspection the certificate for reloo.vn said “Protection Unavailable” because DMCA had not yet scanned/approved the page. The free service is traffic dependent and queued; official guidance: https://www.dmca.com/FAQ/How-do-I-add-a-DMCA-Protection-Badge-to-my-Website . It describes normal free indexing around 24 hours and sometimes up to 48 hours; priority/verified protection is a paid service and was not purchased. Do not claim every page has already been approved. A visible status link allows checking the actual provider outcome.
