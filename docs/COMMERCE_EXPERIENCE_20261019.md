## Price semantics
Product calendar displays daily rate for DAY listings, or an explicitly labelled daily equivalent for WEEK/MONTH. Total rental cost still rounds up by the actual billing period, not the equivalent daily rate. Generic Home/Explore calendars compute the minimum positive rate from active, non-sale-only, unlocked candidates in their current inventory/filter context and label it From. Daily minimum and minimum total are computed independently. No arbitrary global default price, discount or seasonal/date override is invented. This is indicative inventory pricing, not a guaranteed free slot, held booking or complete order total; deposit/delivery excluded. No candidate → no made-up price. Existing server quote is still authoritative.

The requested suggestion and visible GMT+7 lines are removed from calendar UI (including the adjacent selection helper). Seven-hour pickup/default return behavior and Asia/Ho_Chi_Minh computation remain intact. Date selection and hour/minute wheels retained.

## Privacy and API
GET /api/profile retains requireAccount and no-store. Additional contact metadata is derived from authenticated authUser, not client input. A verification badge is true only if the stored profile contact matches that confirmed auth contact (Vietnam phone normalization supported). Google connection is based on actual identity provider membership. Joined date is auth creation date; no identity list or token is exposed. No migration, table/RPC grant or new provider.
